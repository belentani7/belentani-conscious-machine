# BELENTANI // Conscious Machine

## Contenido de la entrega

Este paquete contiene el código fuente del portafolio y una experiencia de archivo con tres dossiers públicos: **NEXUS DATA**, **LumaQuote** y **Cassandra Belentani Complex**. Los textos se limitan a alcance, controles, resultados y límites documentados. No incluye repositorios privados, información de clientes, credenciales, documentos de Drive, inventarios de archivo ni datos personales.

## Experiencia incluida

La portada presenta la práctica bajo la tesis **“sistemas que sostienen una práctica”**. El archivo permite seleccionar los tres casos y abrir un dossier individual para cada uno. Cada dossier expone la tensión inicial, el sistema entregado, señales de evidencia y límites explícitos.

## Desarrollo local

Requiere Node.js 22 y pnpm.

```bash
pnpm install
pnpm dev
```

Para validar y crear la compilación de producción:

```bash
pnpm check
pnpm build
```

## Límites de publicación

Antes de publicar el sitio, confirmar la visibilidad pública de los nombres de proyecto y añadir activos visuales autorizados por cada caso. El formulario de contacto funciona como interacción local y no transmite datos hasta que se conecte un canal de recepción seguro.
